# Modules

This chapter explains how to organize JavaScript code into modules, from the CommonJS system in Node.js to ES6 modules used in modern browsers and runtimes. It covers when and how to use different module systems, import and export patterns, and the bundlers that optimize modules for production.

## Lessons

1. **[01 - Modules](01-modules.md)** — Why modules matter and the basic concept of splitting code into files.

2. **[02 - CommonJS](02-commonjs.md)** — The Node.js module system using `require()` and `module.exports`.

3. **[03 - Strict Mode](03-strict-mode.md)** — Opting into stricter JavaScript rules that catch errors and improve optimization.

4. **[04 - ES6 Modules](04-es6-modules.md)** — The modern standardized module syntax with `import` and `export`.

5. **[05 - Node.js Modules](05-node.js-modules.md)** — How to use CommonJS and ES6 modules in Node.js projects.

6. **[06 - Browser Modules](06-browser-modules.md)** — Using ES6 modules directly in the browser with the `type="module"` attribute.

7. **[07 - Default Exports](07-default-exports.md)** — Exporting and importing a single default value from a module.

8. **[08 - Bundlers](08-bundlers.md)** — Tools like Webpack and Vite that combine and optimize modules for production.
