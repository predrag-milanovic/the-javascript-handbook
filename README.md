# The JavaScript Handbook

A short, skimmable handbook for the parts of JavaScript you actually use.

This is a quick refresher, not a full reference. The chapters are ordered to build from basics to runtime concepts and modules.

## What You Get

- Compact explanations
- Practical chapter-by-chapter notes
- A path from fundamentals to modern JS features

## What Is Not Included

- Framework-specific material like React or Vue
- Deep build-tool coverage
- Long-form theory without practical payoff
